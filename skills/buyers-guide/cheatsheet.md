# Cheat-sheet — Used car buying in Australia

## Before you shop
- [ ] Budget = price + rego + CTP + insurance + fuel + maintenance + loan interest
- [ ] Get an insurance quote on the exact model first
- [ ] Decide dealer vs private vs auction (dealer = most protection)

## Shortlist (carsales-mcp)
- [ ] `search_all_cars` for candidates (carsales + Facebook)
- [ ] `get_listing_details(includeImages: true)` for photos + data
- [ ] Run the **car-inspection** skill on the photos (defects/rust/accident signs)

## Verify BEFORE paying (chapter 04)
- [ ] **PPSR** check — no money owing / stolen / written-off (ppsr.gov.au)
- [ ] State **rego check** — current, not suspended/cancelled
- [ ] **VIN / engine number / plate** on car matches paperwork + listing
- [ ] **Odometer** in photos matches stated km

## Inspect (chapter 02)
- [ ] Even panel gaps, no colour mismatch, no overspray
- [ ] No rust (sills/arch/subframe), no leaks, spare + tools present
- [ ] Test drive on varied roads; seller's insurance covers you
- [ ] **Pre-purchase inspection** by a licensed mechanic (recommended)

## Buy (chapter 05 / 03)
- [ ] Read **contract + finance agreement** before signing
- [ ] Dealer: note **statutory warranty** + **cooling-off** rights
- [ ] Private/auction: almost no protection — extra caution
- [ ] Transfer rego within the state window (e.g. **14 days**, NSW); arrange CTP/green slip

## Red flags — walk away
- Price too good to be true · no inspection · VIN/odometer mismatch ·
pressure to pay now · "no refunds" signs (illegal) · unauthenticated listings.
